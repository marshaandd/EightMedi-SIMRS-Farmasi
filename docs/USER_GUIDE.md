# Panduan Penggunaan EightMedi

## Login
Masuk menggunakan akun yang dibuat pada proses instalasi. Akun demo akan diminta mengganti password pada login pertama.

## Dashboard
Menampilkan ringkasan jumlah obat, pasien, resep, stok rendah, dan status aplikasi.

## Master data
Kelola data obat, kategori, pasien, dokter, poliklinik, dan pemasok. Data yang telah digunakan transaksi sebaiknya dinonaktifkan, bukan dihapus.

## Persediaan
Gunakan Penerimaan untuk menambah stok melalui pemasok. Gunakan Stok keluar/koreksi hanya sesuai SOP demonstrasi. Periksa Riwayat stok setelah transaksi.

## Pelayanan resep
Masukkan kiriman resep dari poli, pilih pasien, dokter, poliklinik, dan obat. Penyerahan dapat dilakukan penuh atau sebagian sesuai persetujuan/SOP yang disimulasikan. Stok berkurang ketika penyerahan berhasil dicatat.

## Laporan
Gunakan filter tanggal dan jenis laporan. Ekspor CSV dapat dibuka di Excel/LibreOffice. Cetak/PDF menggunakan dialog cetak browser.

## Akun
Semua pengguna memiliki tampilan modul operasional yang sama. Administrator dapat membuka menu Pengguna untuk membuat, mengubah, menonaktifkan, dan mereset akun. Pengguna dapat mengganti password sendiri melalui menu Ubah password.
